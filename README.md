# Fan Walmart Assets

Public, immutable source images used by approved Walmart listings from the Fan automation project.

## HJ739550

The eight JPEG files under `HJ739550/` are the approved 2200 x 2200 listing images for seller SKU `AI-HJ739550`. Each filename includes the image SHA-256 digest.

Listing payloads use the public GitHub Pages HTTPS URLs. Hash-addressed filenames prevent later repository changes from silently replacing submitted image content.
